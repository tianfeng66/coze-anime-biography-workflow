# 动漫人物传记视频工作流（扣子）

一个可导入扣子（Coze）的低代码工作流草稿：输入人物或人物设定，生成 16:9 横屏动漫人物传记视频的分镜脚本、人物参考图、逐镜头视频、中文旁白、字幕和拼接结果。

> 状态：**草稿 / 未实跑验证**。仓库公开的是工作流配置，不是打开网页即可直接生成视频的在线服务。导入后请先用少量分镜调试，并检查模型、插件、额度与输出质量。

## 下载与导入

1. 下载仓库中的 [`Workflow-zimeititwo-draft-fixed.zip`](./Workflow-zimeititwo-draft-fixed.zip)。请下载这个 ZIP 文件本身，不要使用 GitHub 的“Download ZIP”仓库压缩包。
2. 在扣子工作空间的资源库中选择“导入工作流”，上传该 ZIP。扣子会读取工作流名称与描述；导入后默认是草稿。
3. 检查并按所在工作空间重新配置图片生成、视频生成、语音合成和视频剪辑节点。跨空间导入时，插件或其他资源可能需要重新选择。
4. 填好开始节点参数，先用 `scene_count = 3` 试运行。确认分镜、音画、字幕和最终视频链接后再增加镜头数量。

扣子官方的[工作流导入与导出说明](https://docs.coze.cn/guides_import_and_export_workflow)介绍了 ZIP 格式、导入位置、套餐要求和跨空间资源限制。导入功能可能需要付费套餐；视频生成、语音合成及视频剪辑也可能产生费用，请以平台实际提示为准。

## 输入参数

| 参数 | 用途 | 建议 |
| --- | --- | --- |
| `subject_input` | 人物名称或原创人物设定 | 必填；真实人物请提供可核实的资料 |
| `life_story` | 用户提供的生平经历 | 可选；填写后作为主要事实来源 |
| `scene_count` | 分镜数量 | 建议 3–6；当前提示词只明确规定了这几种结构 |
| `visual_style` | 画面风格 | 例如“手绘动漫电影风格，柔和暖色光影” |
| `story_tone` | 旁白语气 | 例如“克制、温暖、口语化” |
| `language` | 预留输入 | 当前生成逻辑未接入；旁白和字幕固定为简体中文 |

## 处理流程

`人物输入 → 分镜脚本 → 人物参考图 → 逐镜头首帧图 → 10 秒视频 → 中文旁白 → 音画合并 → 字幕 → 完整视频拼接`

批处理节点最多处理 6 个分镜，当前并发数为 2。单个视频生成节点配置为 16:9 参考图驱动、10 秒、480p。最终输出包括视频标题、封面文案、分镜脚本、人物参考图、逐镜头素材和完整视频链接。视频链接由扣子节点生成，可能有有效期；需要长期保存时请及时下载。

## 这份公开副本的修正

相对于用户提供的原始导出草稿，公开 ZIP 只做了两类最小修正：

1. 将开始节点的 `life_story` 接入“分镜生成”节点，使用户填写的经历能进入提示词。
2. 把提示词末尾两处“每镜头 8 秒”改为 10 秒，与同一提示词前文及视频生成节点的 10 秒设置一致。

其余节点和连线保持原草稿配置。工作流没有在扣子平台上完成导入及端到端运行验证，实际运行前请检查节点可用性、旁白与视频时长匹配、字幕位置、人物一致性和拼接结果。真实人物的经历和成就应人工核对，生成内容不应直接视为事实。
